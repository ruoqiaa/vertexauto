# Autolock Smith
![Autolock Smith Screenshot](Screenshot%202026-08-15%20at%2013.10.37.png)

A one-page business website built for Autolock Smith (Express Car Key), a car locksmith service, designed to convert visitors into enquiries.

🔗 **Live site:** [expresscarkey.co.uk](https://expresscarkey.co.uk)

## What it does
- Single-page static site showcasing services
- Clear calls-to-action to drive customer enquiries/contact
- Clean, fast-loading business site

## Built with
- HTML
- CSS
- JavaScript

## About this project
This was my first web project — a real client site built for a local locksmith business to help them establish an online presence and generate leads.
